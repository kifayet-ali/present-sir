PRESENT SIR — RESPONSIVE LMS UI PROTOTYPE

Stack: HTML5, CSS3, simple PHP. No database, SQL or JavaScript.

SETUP
1. Install XAMPP or another PHP-enabled local server.
2. Extract the present-sir folder into htdocs.
3. Start Apache.
4. Visit http://localhost/present-sir/
5. Open Login, choose a role, and click Enter Dashboard.

IMPORTANT LIMITATIONS
- Login/signup/password reset and forms are UI demonstrations, not real authentication or persistence.
- Dashboard records are illustrative sample data.
- Quiz demo checks a single answer with PHP and does not save results.
- Live countdown, auto-submit, tab-switch monitoring, randomization and anti-cheating require future JavaScript and server-side implementation.
- External Google Fonts are optional; Arial fallback is included.
- Navigation between sections works via PHP pages.

THEME: Navy #142D4E, Royal Blue #2563EB, Teal #0D9488.
